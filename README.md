## 口径

- 难度：最高进阶 A10
- 模式：单人、标准模式
- 版本：v0.107 / v0.111
- 职业：铁甲战士、静默猎手、故障机器人、亡灵契约师、储君
- 数据来源：sts2log.com/cards
- 数据采集日期：2026-09-17

图册中的“出现胜率”近似按

`出现胜率 ≈ 选取率 × 选择后胜率 + (1 − 选取率) × 跳过后胜率`

计算。每个职业同时给出对应先古的平均出现胜率，并标注每件遗物在同版本、同职业、同先古内的出现胜率排名。

`n < 100` 的小样本项不纳入组内均值和排名。

## 说明

这些统计反映当前玩家策略与对应提供条件下的结果，不应直接解释为遗物本身的纯因果强度。不同先古、不同版本及不同提供条件之间也不宜仅凭绝对胜率直接横向比较。
